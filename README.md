# 🎡 Yes/No Color Wheel

A simple interactive web application that helps users make quick decisions by spinning a colorful wheel.

## Features

- Random Yes/No selection
- Interactive spinning wheel
- Simple and responsive design
- Built using HTML, CSS, and JavaScript

## How to Use

1. Open the application.
2. Click the spin button.
3. Wait for the wheel to stop.
4. See the result!

## Technologies Used

- HTML
- CSS
- JavaScript
